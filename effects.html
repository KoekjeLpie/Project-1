Score File Format

The score file and audio features the different types of effects applied onto the audio notes. There are parameters like wet and dry mix, or enable tags to control how the effects alter the sounds.

  • Baseline: A note is played with no effect applied.
  • Noise gating: Noise gate is applied onto the note to cut sound below a certain volume and removing unnessary noise.
  • Ring modulation + controllable send: Multiplies the note signal with sine wave to create a metallic robotic tone. A 50/50 wet and dry mix is in to show controllable send.
  • Flanging: Flang effect gives the note a swooshing jet-engine phase effect.
  • Chorus: Chorus is similar to flanging, but uses longer delays onto the sound.

Below is the score file format for this component demonstration.

<?xml version="1.0" encoding="utf-8"?>
<!-- ======================================================================= -->
<!-- EFFECTS COMPONENTS                                                      -->
<!-- ======================================================================= -->
<score bpm="120" beatspermeasure="4">

   <!-- ======================================================================= -->
   <!-- BASELINE: NO EFFECT                                                     -->
   <!-- ======================================================================= -->
   <instrument instrument="ToneInstrument">
      <note measure="1" beat="1" duration="1.8" note="C4"/>
      <effects wet="0.0" dry="1.0" gateEnable="false" ringModEnable="false" flangeEnable="false" chorusEnable="false"/>
   </instrument>

   <!-- ======================================================================= -->
   <!-- EFFECT 1: NOISE GATING                                                  -->
   <!-- ======================================================================= -->
   <instrument instrument="ToneInstrument">
      <note measure="2" beat="1" duration="1.8" note="C4"/>
      <effects gateEnable="true" gateThreshold="0.20" wet="1.0" dry="0.0" ringModEnable="false" flangeEnable="false" chorusEnable="false"/>
   </instrument>

   <!-- ======================================================================= -->
   <!-- EFFECT 2: RING MODULATION + CONTROLLABLE SEND                           -->
   <!-- ======================================================================= -->
   <instrument instrument="ToneInstrument">
      <note measure="3" beat="1" duration="1.8" note="E4"/>
      <effects ringModEnable="true" ringModFreq="440.0" wet="0.5" dry="0.5" gateEnable="false" flangeEnable="false" chorusEnable="false"/>
   </instrument>

   <!-- ======================================================================= -->
   <!-- EFFECT 3: FLANGING                                                      -->
   <!-- ======================================================================= -->
   <instrument instrument="ToneInstrument">
      <note measure="4" beat="1" duration="1.8" note="G4"/>
      <effects flangeEnable="true" flangeFreq="1.2" flangeDepth="0.003" wet="0.8" dry="0.8" gateEnable="false" ringModEnable="false" chorusEnable="false"/>
   </instrument>

   <!-- ======================================================================= -->
   <!-- EFFECT 4: CHORUS                                                        -->
   <!-- ======================================================================= -->
   <instrument instrument="ToneInstrument">
      <note measure="5" beat="1" duration="1.8" note="C4"/>
      <effects chorusEnable="true" chorusFreq="0.4" chorusDepth="0.006" wet="0.7" dry="0.7" gateEnable="false" ringModEnable="false" flangeEnable="false"/>
   </instrument>

</score>
