Score File Format

Basic Description of Score File

The score file uses XML to define tempo and instruments. The score file has a bpm setting to adjust the speed of the audio. The score file contains a duration setting, allowing the number of beats the note can play. There are also multiple enable tools to adjust effects onto the note or to select an instrument.

Description of Score File for Music

The score file used to make the song is a combination of ToneInstrument and SubtractiveInstrument notes. The SubtractiveInstrument plays the bass clef notes and chords with filter envelopes, while the ToneInstrument plays the main melody.

Below is a sample of what the format looks like for the score file.


<?xml version="1.0" encoding="utf-8"?>
<score bpm="89" beatspermeasure="4">
  <instrument instrument="ToneInstrument">
    <note measure="1" beat="1" duration="2.0" note="F4"/>
    <note measure="1" beat="1" duration="2.0" note="A4"/>
    <note measure="1" beat="1" duration="2.0" note="D5"/>
  </instrument>
  <instrument instrument="SubtractiveInstrument">
    <note measure="1" beat="1" duration="2.0" note="D3" waveform="saw" resonFreq="350" resonBand="25">
      <envelope attack="0.05" decay="0.3" sustain="0.8" release="0.4"/>
      <filterEnvelope attack="0.2" decay="0.4" sustain="0.2" release="0.3"/>
    </note>
  </instrument>
</score>
